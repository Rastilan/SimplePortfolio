##  Getting Started

***Requirements***

Ensure you have the following dependencies installed on your system:

* **JavaScript**: `version x.y.z`

###  Installation

1. Clone the SimplePortfolio repository:

```sh
git clone https://github.com/Rastilan/SimplePortfolio
```

2. Change to the project directory:

```sh
cd SimplePortfolio
```

3. Install the dependencies:

```sh
npm install
```

###  Running SimplePortfolio

Use the following command to run SimplePortfolio:

```sh
npm run dev
```
